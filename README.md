# 🏢 Employee Directory - ระบบแนะนำพนักงานให้ทีม

[![Node.js Version](https://img.shields.io/badge/Node.js-18.x-green.svg)](https://nodejs.org/)
[![Express Version](https://img.shields.io/badge/Express-4.18.x-blue.svg)](https://expressjs.com/)
[![MySQL Version](https://img.shields.io/badge/MySQL-8.0-orange.svg)](https://www.mysql.com/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

เว็บแอปพลิเคชันสำหรับจัดการข้อมูลพนักงานในองค์กร รองรับการเพิ่ม แก้ไข ลบ และค้นหาพนักงาน พร้อมระบบกรองตามแผนก

## ✨ Features

### 🎯 Core Features
- 📋 **แสดงรายชื่อพนักงาน** - แสดงข้อมูลแบบการ์ดพร้อมรูปภาพ
- 🔍 **ค้นหาพนักงาน** - ค้นหาตามชื่อหรือตำแหน่งงาน
- 🏷️ **กรองตามแผนก** - กรองพนักงานตามแผนกที่เลือก
- ➕ **เพิ่มพนักงาน** - เพิ่มพนักงานใหม่ผ่านฟอร์ม
- ✏️ **แก้ไขพนักงาน** - แก้ไขข้อมูลพนักงานที่มีอยู่
- 🗑️ **ลบพนักงาน** - ลบพนักงานพร้อมระบบยืนยัน

### 🎨 UI/UX
- 💎 **Modern Design** - ดีไซน์ทันสมัยด้วย Gradient และ Animation
- 📱 **Responsive** - รองรับทุกขนาดหน้าจอ (Desktop, Tablet, Mobile)
- ⚡ **Real-time Updates** - อัพเดทข้อมูลทันทีโดยไม่ต้องรีเฟรชหน้า
- 🎯 **User-friendly** - อินเทอร์เฟซใช้งานง่าย เข้าใจได้ทันที

### 🔒 Security
- ✅ **Data Validation** - ตรวจสอบข้อมูลก่อนบันทึก
- ✅ **Unique Email** - ป้องกันการใช้อีเมลซ้ำ
- ✅ **SQL Injection Protection** - ใช้ Prepared Statements
- ✅ **CORS Enabled** - กำหนดสิทธิ์การเข้าถึง API

## 🛠️ Technologies

### Frontend
- **HTML5** - Semantic HTML
- **CSS3** - CSS Grid, Flexbox, Animation, Gradients
- **JavaScript (ES6+)** - Async/Await, Fetch API, DOM Manipulation
- **Font Awesome 6** - Icons
- **Google Fonts (Prompt)** - Thai font

### Backend
- **Node.js** - Runtime Environment
- **Express.js** - Web Framework
- **MySQL2** - Database Driver
- **CORS** - Cross-Origin Resource Sharing
- **Dotenv** - Environment Variables
- **Body-parser** - Request Body Parser

### Database
- **MySQL** - Relational Database
- **Indexed** - Optimized queries with indexes
